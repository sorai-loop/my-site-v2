# 我がサイト
作ったもの置いたりハマってるものを置いたり、記事配置したり...
モバイルファーストで作成する。
基本的に各セクションを表示画面最大幅で。
## 構造
### Hero
一番最初に出てくる画面。
soraiの文字と雲のsvgを2つくらい配置する。
### Sign
目次。
モバイルだと他セクションと同じで画面サイズ最大だが、PC等のある程度大きい画面ならそれ以降常に画面左に常駐するような形にする。
### Works
これまで作ったものを配置する。
現状いいデザインが思いついていない。
### Articles
これまで投稿した記事を飾る。
現状使っているのがQiitaなのでAPIで情報を取ってきたい。
本棚をイメージしたデザインにしたい。
### Profile
私について。
所属や活動歴、ハマってる曲やOSとかトピックとかgithubの草表示したり...
## 使用技術
- React
- Type Script
- CSS Modules
- Qiita API
