#### 棚
Qiitaから取得した記事データを流し込み、スチームパンク風の配管本棚としてレンダリングする。
データ駆動設計により、上位セクションからは記事配列を渡すだけで、段数分割・蛇行配管・本の姿勢決定を自動構築する。

##### Book.tsx
- タイトル、いいね数が書かれた1冊の本（背表紙）を描画するコンポーネント。
- 本文文字数（`charCount`）に応じた横幅や高さ（薄型/中型/大型）をクラスで動的に切り替える。
- タイトルの文字数に応じた縦書きフォントサイズ調整、およびタグ一致状態に応じたハイライト/半透明表示（`bookMatched` / `bookDimmed`）を持つ。

##### PipeBookshelf.tsx
- 記事配列（`articles`）と選択中タグを受け取り、蛇行する配管本棚を自動構築して縦スクロール可能に表示するビューポートコンポーネント。
- 選択されたタグに一致する記事を先頭にソートし、4冊区切りで `Shelf` の配列を生成する。
- 蛇行配管の接続整合性を保つため、最低2段かつ偶数段（L字と反転L字のペア）を保証する。
- スクロールイベントを上位（速度計など）へ中継する。

##### Shelf.tsx
- `ShelfBooks` と `ShelfPipe` を組み合わせて棚の1段を作成するコンポーネント。
- 棚の段数インデックス（偶数/奇数）から、配管の向き（L字 / 反転L字）と本の配置方向（左詰め / 右詰め）を決定する。
- 水平直パイプの天面に本を着地させ、左右の縦柱パイプと本が重ならない表示領域のレイアウトを司る。

##### ShelfBooks.tsx
- 棚1段分の本（最大4冊）を並べるコンポーネント。
- 本の下部が水平直パイプの天面に着地し、隣り合う本の境界線（2px）が干渉して太くならないよう重なり順（z-index）やマージンを制御する。
- 傾き姿勢の本（`tiltedLeft` / `tiltedRight`）に対して、本の高さと傾き角度から算出したオーバーハング分のパディングを適用して自然に寄りかからせる。

##### ShelfPipe.tsx
- 棚1段分の配管骨組みを描画するコンポーネント。
- `Shelf` から渡される `variant`（`L` または `reversed-L`）に応じて、縦柱直パイプ、90度エルボ、水平直パイプ、各種装飾継手（ユニオン、六角ナット、ネジ山、そろばん玉）を組み上げて蛇行配管を形成する。

##### ArticlesControlPanel.tsx / ControlPanelPipeFrame.tsx
- 記事セクションの操作パネル。配管フレーム枠（`ControlPanelPipeFrame`）内に、総数カウンタ、スクロール連動アナログ速度計（`SpeedMeter`）、タグフィルターボタン群を配置する。
- 配管フレームは画面幅に合わせて伸縮するレスポンシブ設計を持つ。


### Stacks
自分のできる技術・武器・経験についてのメモ書き。
冒険者の「装備・術式の手控えノート（インベントリ手帳）」として設計する。

#### デザイン・構造方針
- 1セクション＝手記の1ページ
  - ノートのヘッダ線・タイトル線そのものが、セクションタイトル（`h2`）の装飾枠を兼ねる。
  - 基本行高（`--line-height`）と同期したメモ帳風罫線の上に、手書き文字が綺麗に着地する。
- 付箋インデックス手帳方式
  - 各技術に2〜5行のしっかりした所感・エピソードを書きたい場合でも縦に間延びせず、心地よいスクロール量に収める。
  - トラベラーズノートの小口（ページの右端）に沿って縦長・縦書きの付箋インデックスを縦並びで配置。
    - **PC**: ノートの右外側にピョコッと飛び出し、手帳の背表紙・小口に貼られたリアルな縦長・縦書きインデックスとして表示。
    - **スマホ**: 数字インデックスは消し、ページの右縁に沿ってスリムな縦長・縦書き付箋として配置し、本文幅を圧迫しない設計。
  - 歯車やベルトコンベアのギミックを取り入れる場合は、主役（手記）を邪魔しない手回し切り替え機構や、余白・ヘッダーの落書き・装飾帯フレーバーとして添える。

#### タブ構成
1. 01. Languages
   - 言語ごとの特徴、思想、愛着などのメモ。
2. 02. Frameworks & Platforms
   - React、Vite、Linux、Raspberry Pi等の環境やフレームワーク。
3. 03. Tools & Others:

#### 各アイテムの配置レイアウト
- 左側: アイコン枠（`StackIcon`）
  - 手押しスタンプのような自然な微小傾き（`-2.6°` 〜 `+2.6°`）をハッシュ値から決定論的に付与（リロードやSSRでも同一角度を維持）。
  - ホバー時に浮き上がりと微小回転のアニメーション。
  - **アイコンの追加運用**: ダウンロードしたSVGファイルを `src/assets/svg/Stacks/` に配置し、データ側（`src/data/stacks.ts`）にファイル名（例: `'TypeScriptIcon.svg'`、拡張子なし `'TypeScript'` 等）を指定するだけで自動解析・自動染色。
  - **フォールバック**: SVG未配置時は自動で英数字3文字のクラシックモノグラム（例: `RUS`, `GLS`）として生成。外部URL・パス指定時は `mask-image` で型抜き染色。
- 右側: 技術分類ラベル（`// ドメイン名`）＋ 技術名（少し大きめの手書き文字）（罫線2行分） ＋ 2〜5行のこだわりメモ・エピソード（罫線に着地）
- 1アイテムごとに罫線1行分の空行（余白）を挟み、ノートらしいゆったりとした垂直リズムを確保する。

#### 罫線とグリッドの同期仕様
- **基準行高**:
  - CSS変数で定義する行高を基準とし、セクション内の高さ・マージン・行間をその整数倍で管理する。
- **ベースライン着地**:
  - テキスト（`font-family: var(--font-base)` / Klee One）の底辺が、罫線の真上にぴったり着座するようにパディング・ラインハイトを調整する。
- **アイテムの垂直リズム**:
  - 技術名: 罫線1〜2行分
  - メモ本文: 罫線2〜5行分
  - アイテム間の区切り: 罫線1行分の空行（マージン）
  - これにより、文章量が増減しても下流のテキストと罫線の位相が絶対にズレない。
- **左マージン線（縦ガイド線）**:
  - アイコン・スタンプ領域（左側）と、技術名・メモ本文領域（右側）の間に、ノート特有の縦ガイド線を敷く。

## メモ帳風罫線の設計
メモ帳のような横線を背景やテキスト周りに取り入れる際の設計方針。
基準モチーフとして**「トラベラーズノート（レギュラーサイズ・横罫リフィル：28行）」**をベースとする。
ヘッダ線、タイトル線、ノートのページ下部にあるそのページの罫線の終わり辺りの太い線を置く。

最下部の下にある若干の空白をサイト内ではセクションごとの余白として表現する。

### 基準寸法とページ構成
- **モチーフ**: トラベラーズノート レギュラーサイズ（H210 × W110mm、A4三つ折りのスリムな手記紙面）
- **1ページの罫線数**: **28本（28行）** を基準とする。
- **基本比率**: 1行の高さ : 上部余白 ＝ 1 : 3
- **線の太さ**: 1px（または 0.5px）

### テキスト同期の仕組み
- 1枚絵の大きなSVGを敷くのではなく、1行分のSVGを用意する。
- CSS変数をハブにし、テキストの `line-height` と背景の `background-size`に同じ `rem` 値を指定して完全同期させる。
- 背景を固定（`fixed`）にせず、コンテンツ要素自身の背景としてスクロールと一緒に流れるようにする。
- 1セクションを1ページとみなす
  - そのページのヘッダ線やタイトル線が実際にセクションタイトルであるh2等を装飾するイメージ。
  - HeroとSignセクションは手記の最初のなんの線も引かれていないページのイメージなので適用外。

### ベースライン着地（文字の着座）
- 通常のWebテキストは行の中央に配置されるため、そのままでは文字が罫線の中央に浮いてしまう。
- 文字の底辺（ベースライン）が罫線の真上にぴったり重なるよう、微小なパディングやオフセットで「線の上に文字が着座している」状態を担保する。

### 垂直リズム（グリッド整合性）
- 余白（`margin`, `padding`, `gap`）や空行を任意の値にせず、すべて基準行高の整数倍で管理する。
- これにより、文章量の増減やアイテムの追加があっても、ページ全体の罫線と文字がズレることなく同期し続ける。

### 共通レイアウトコンポーネント（NotebookSection）
各セクションで罫線やヘッダ・フッターのロジックを重複させず、共通して上から適用できるように `src/components/section/NotebookSection.tsx` として独立。
- **Props**:
  - `id`: セクションDOMのid（ページ内リンク用）
  - `title`: セクション大見出し（`h2`）
  - `subtitle`: セクション副題
  - `pageCode`: ページ章コード（例: `PAGE. 03 // STACKS`）
  - `categoryBadge`: タイトル線上のカテゴリ表示スロット
  - `headerAccessory`: 右上のアクセサリ（歯車、スタンプ等）スロット
  - `sideTabs`: 小口（右端）の縦長付箋スロット
  - `hasLeftMarginLine`: 左マージン線（縦ガイド線）の有無
  - `minLines`: 基準行数（デフォルト: トラベラーズノートの28行）
  - `footerCode`: 最下部太線の終端コード
  - `footerAction`: 最下部太線のアクションスロット
- 今後、WorksやProfile等のセクションにも `<NotebookSection>` を上から被せるだけで、同一のトラベラーズノート罫線ページとして統合可能。

## コンポーネント
### StampGraphic
その名の通り、印鑑・スタンプ風のバッジを描画するSVGコンポーネント（`src/components/ui/StampGraphic.tsx`）。
`src/assets/svg/Stamp.svg` をベースに、動的なテキスト描画、朱文・白文の切り替え、輪郭のにじみおよびインクの色ムラのテクスチャを備える。

#### 仕様
- 印種（朱文・白文）
  - `type={0}`（デフォルト）: 朱文。外枠と文字にインクが乗り、背景は透過。
  - `type={1}`: 白文（陰刻）。朱文と同じ最大外周線 + 隙間を設けた内側ベタ塗りブロックから文字をくり抜くデザイン。
- スタイル継承
  - インク色: 親要素の文字色（`currentColor`）を継承。親要素の `color` や CSSクラスで変更可能。
  - フォント: 親要素の `font-family` を継承。
  - サイズ: デフォルトは `height: 1.25rem; width: auto; aspect-ratio: 52 / 19;`。親要素や `className` の `height` を指定すれば、拡大・縮小可能。
  - 文字長自動調整: 7文字を超える場合は `textLength` と `lengthAdjust` により自動で枠内に収まるよう水平圧縮される。
- テクスチャ
  - 輪郭のブレ・歪み（`bleed={false}` で無効化可能）。
  - 色ムラ。

#### Props定義
| Prop | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| `text` | `string` | 必須 | スタンプ内に表示するテキスト |
| `type` | `0 \| 1` | `0` | スタンプの形式（`0`: 朱文 / `1`: 白文） |
| `bleed` | `boolean` | `true` | 輪郭のにじみ・歪みフィルターの有無 |
| `className` | `string` | `undefined` | サイズや配置調整用の追加CSSクラス名 |
| `aria-hidden`| `boolean \| 'true' \| 'false'` | `true` | アクセシビリティ用属性 |

#### 呼び出し方法
```tsx
import { StampGraphic } from '@/components/ui/StampGraphic';

// 1. 基本的な呼び出し（朱文・デフォルトサイズ）
<StampGraphic text="SAMPLE" />

// 2. 白文（陰刻）
<StampGraphic text="COMPLETED" type={1} />

// 3. にじみオフ
<StampGraphic text="DRAFT" bleed={false} />

// 4. CSSクラスでインク色やサイズを指定
// CSS側: .redStamp { color: #d32f2f; height: 2rem; }
<StampGraphic text="REJECTED" type={1} className={styles.redStamp} />

// 5. 親要素から色やフォントを継承させる
<div style={{ color: '#2e7d32', fontFamily: 'serif' }}>
  <StampGraphic text="ACCEPTED" type={0} />
</div>
```

### NotebookSection
手記の1ページを表現する共通レイアウトワッパーコンポーネント（`src/components/section/NotebookSection.tsx`）。
トラベラーズノート（レギュラーサイズ・横罫28行）をモチーフとし、天余白（1:3）・ヘッダ線・タイトル線・本文背景（`RuledLine.svg` による1行背景リピート）・左マージン線・フッター太線を一元管理する。

#### Props定義
| Prop | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 必須 | セクションDOMのid（ページ内リンク用） |
| `title` | `string` | 必須 | セクション大見出し（`h2`） |
| `subtitle` | `string` | `undefined` | セクション副題 |
| `pageCode` | `string` | `undefined` | ページの章コード（例: `'PAGE. 03 // INDEX-01'`） |
| `categoryBadge` | `ReactNode` | `undefined` | タイトル線右側に表示するカテゴリバッジや補足情報 |
| `headerAccessory` | `ReactNode` | `undefined` | ヘッダ線右上に配置するアクセサリ（歯車、日付等） |
| `sideTabs` | `ReactNode` | `undefined` | 小口（右端）の縦長インデックス付箋スロット |
| `hasLeftMarginLine` | `boolean` | `true` | 左マージン線（赤い縦ガイド線）の有無 |
| `minLines` | `number` | `28` | 基準行数（トラベラーズノートの28行） |

### StackIcon
手記・製図風の刻印枠と、外部から導入したSVGアイコンをサイトの世界観（インク・朱肉・用紙色）で多色自動上塗りするワッパーコンポーネント（`src/components/ui/StackIcon.tsx`）。

#### 仕様・特徴
- **製図フレーム**: 実線外枠と点線内枠による手記刻印風の外枠を自動合成。
- **スタンプノイズ＆ステイン**: `StampGraphic` と同様の `feTurbulence`（輪郭のにじみ・ギザギザノイズ）と `feComposite` / `feComponentTransfer`（インクのかすれ・濃淡ステイン）を外枠および内側のアイコンSVGへ自動適用。SVGの各viewBox座標系に応じてノイズ周波数と変位スケールを自動補正。
- **ファイル名・相対パス指定の自動上塗り**: キー定義不要。`src/assets/svg/Stacks/` 配下のSVGファイル名（例: `'RaspberryPiIcon.svg'`）や拡張子なし名、正規化名を渡すだけで、SVG内部の色を自動解析し、サイトの文字色に準拠した基本3色＋透過（メイン: 本文文字色 `#36332f`、サブ: 褪色セピア `#7a6c5d`、アクセント: 刻印朱肉 `#dc3f24`、透過: 用紙色 `#fffdf4` / `transparent`）の単一パターンへ自動置換してレンダリング。
- **フォールバック**: SVG未配置時は自動で3文字モノグラム（例: `RUS`, `GLS`）を表示。外部URL・パス指定時は `mask-image` で型抜き染色。
- **メンテナンスフリー**: 新しい技術アイコンを追加する際は、SVGファイルを配置してデータ側（`stacks.ts`）にファイル名を書くだけで完了（コンポーネント側のコード変更は一切不要）。

## ユーティリティ
### stackSvg（`src/utils/stackSvg.ts`）
外部SVGアイコンの解析・手記パレット自動上塗りユーティリティ。

- `resolveSvgText(input?: string): string | null`:
  `src/assets/svg/Stacks/` 配下のSVGを Vite の `import.meta.glob(..., { query: '?raw', eager: true })` で一括インポートし、キャッシュ辞書を用いた O(1) 高速解決（完全一致、ファイル名、拡張子なし、正規化名、部分一致フォールバック）。
- `mapColorToPalette(hexOrName: string): string`:
  SVG内の色を解析し、HSL（明度・彩度・色相）からサイトの基本4色（石墨インク、褪色セピア、刻印朱肉、用紙色/透過）へ自動分類。
- `recolorSvg(rawSvg: string, options?: RecolorOptions): string`:
  SVGソース文字列内のカラー指定を上記パレットへ一括置換。さらに、viewBox 座標系サイズを自動抽出し、それに連動した `feTurbulence`（輪郭にじみ）と `feComposite`（ステインかすれマスク）を動的生成・注入。

## Lintに書きたいもの
### ファイルの命名規則
- src/components/ui直下のファイルは`*Graphic.tsx`か`*Icon.tsx`のみとする。
- src/components/section直下は`*Section.tsx`のみとする。
- src/assets/svg直下のファイルはパスカルケースのみとする。
### .tsx
- svgの直接importを禁止する。
- 装飾目的のSVGオブジェクトに対して、`aria-hidden="true"`を付与する。
- クリック可能なアイコンに対して`aria-label`を付与する。
### .module.css
- 存在しないクラス名を.tsxで参照した場合、エラーとする。
